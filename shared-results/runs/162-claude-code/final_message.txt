## Local Development Setup

**Prerequisites:** Python 3.12, and [`uv`](https://docs.astral.sh/uv/getting-started/installation/)

### 1. Install dependencies
```bash
uv sync
```

### 2. Install Playwright browsers (required for crawlers)
```bash
uv run playwright install chromium
```

### 3. Create your config file
```bash
cp "config example.yaml" config.yaml
# Edit config.yaml to set your filters, districts, enabled sources, etc.
```

### 4. Set Telegram credentials
Create/edit `.env` with your bot credentials (do **not** commit this file):
```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHANNEL_ID=your_channel_id_here
```

### 5. Verify setup
```bash
uv run python cli.py test-telegram
```

### 6. Run a crawl
```bash
uv run python cli.py run
```
