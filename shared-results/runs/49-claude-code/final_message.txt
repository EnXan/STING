**Before running**, you'll need to set Telegram credentials in your environment:
```bash
export TELEGRAM_BOT_TOKEN="your_token"
export TELEGRAM_CHANNEL_ID="your_channel_id"
```

Then test and run with:
```bash
UV_CACHE_DIR=/tmp/uv-cache uv run python cli.py test-telegram
UV_CACHE_DIR=/tmp/uv-cache uv run python cli.py run
```

The `UV_CACHE_DIR` override is needed because the default cache path (`~/.cache/uv`) has a permissions issue in this environment. You can also add `export UV_CACHE_DIR=/tmp/uv-cache` to your shell profile to avoid typing it each time.
