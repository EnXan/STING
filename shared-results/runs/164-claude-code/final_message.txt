**To use the project**, you need two things:

1. **Edit `config.yaml`** — adjust filters (rooms, price, districts) for your search criteria.

2. **Set environment variables** for Telegram notifications:
   ```bash
   export TELEGRAM_BOT_TOKEN="your_bot_token"
   export TELEGRAM_CHANNEL_ID="your_channel_id"
   ```

**Then run:**
```bash
uv run python cli.py test-telegram   # verify Telegram works
uv run python cli.py run             # run a crawl
uv run python cli.py stats           # view database stats
```
