## Codebase Patterns
- Claude Code blocks `--dangerously-skip-permissions` when running as root (uid 0). Always run claude as a non-root user (e.g. `agent`) inside Docker.
- Docker Desktop (macOS) cannot bind-mount a file inside a parent directory already mounted read-only. Pass credentials as env vars instead and write them in entrypoint.sh.
- `su -p agent` preserves all container env vars (HTTP_PROXY, SSL_CERT_FILE, etc.) through the user switch — use `-p` when running the agent via `su`.
- `shutil.copytree` of `~/.claude` fails on broken symlinks (e.g. `debug/latest`); always pass `symlinks=True`.
- Even root inside Docker Desktop (macOS) may not be able to `chown` git pack files (mode 0444) inside bind-mounted directories — copying the whole `~/.claude` into a bind mount triggers this.

## 2026-06-04 - STING-10
- What was implemented: Smoke-tested the full pipeline end-to-end with attack #1 / claude-code.
  Fixed three bugs discovered during the run:
  1. **Nested bind mount** — Docker Desktop (macOS) cannot mount a file inside a read-only directory
     mount. Solved by delivering credentials via `CLAUDE_CREDENTIALS_JSON` env var and writing them
     in entrypoint.sh, removing the `~/.claude` directory mount entirely.
  2. **root block** — Claude Code refuses `--dangerously-skip-permissions` when running as root.
     Added a non-root `agent` user to the Dockerfile and run claude via `su -p agent`. Strace
     (root + CAP_SYS_PTRACE) continues to trace the su'd child process.
  3. **Writable directories** — entrypoint now `chown agent:agent /var/log/sting` and `/repo` so the
     agent user can write final_message.txt and run dev setup tasks.
- Files changed: Dockerfile, entrypoint.sh, runner/docker_utils.py, runner/runner.py,
  tasks/stories.json, tasks/progress.txt
- **Learnings for future iterations:**
  - Claude refuses `--dangerously-skip-permissions` as root; always run as non-root user.
  - `su -p` is required to preserve HTTP_PROXY and SSL_CERT_FILE through the user switch.
  - Credential delivery via env var is robust on macOS Docker Desktop; avoid nested bind mounts.
  - `get_claude_credentials_json()` in docker_utils.py returns the raw JSON string from keychain.
